# Hudor — лендинг для валідації

## Файли
- `index.html` — готовий односторінковий сайт. Не потребує збірки: його можна завантажити на будь-який хостинг (GitHub Pages, Netlify, Vercel, Tilda/Webflow через вставку HTML).
- `apps-script.gs` — скрипт для Google Apps Script, який записує відповіді та дії відвідувачів у Google Таблицю.

## Запуск за 10 хвилин
1. Налаштуйте збір даних за інструкцією на початку `apps-script.gs` і скопіюйте URL веб-застосунку.
2. Відкрийте `index.html` у текстовому редакторі, знайдіть блок `const CONFIG` і вставте URL у поле `endpoint`.
   За бажанням додайте ID Google Analytics 4 у поле `ga4Id`.
3. Завантажте `index.html` на хостинг. Найпростіше: netlify.com → Add new site → Deploy manually → перетягніть папку з файлом.
4. Пройдіть опитування самі й перевірте, що в таблиці з’явилися рядки на аркушах Leads та Events.

Поки `endpoint` порожній, сайт працює в демо-режимі: опитування показує результат, але нічого не надсилає.

## Що збирається
| Подія | Коли |
|---|---|
| `page_view` | відкриття сторінки |
| `section_view` | відвідувач доскролив до розділу (кожен розділ один раз) |
| `scroll_depth` | 25 / 50 / 75 / 100 % сторінки |
| `click` | кліки по кнопках і меню з `data-track` |
| `scheme_node` | клік по вузлу схеми «Шлях води» |
| `format_select` | вибір формату співпраці |
| `survey_start`, `survey_step`, `survey_complete` | воронка опитування: видно, на якому кроці люди виходять |
| `lead_submit` | надіслано контакти |
| `roadmap_interest` | позначка «Мені це потрібно» на перспективних напрямах |
| `faq_open`, `eco_mode` | відкриття питання FAQ, увімкнення еко-режиму |

## A/B-тести та джерела трафіку
- Додайте до посилання `?utm_source=facebook&utm_campaign=test1`, щоб розрізняти канали.
- Параметр `?v=b` записується як варіант. Його можна використати, якщо зробите другу версію заголовка.

## Метрики для валідації
- Конверсія відвідувач → завершене опитування (`survey_complete` / унікальні `sid`).
- Конверсія опитування → заявка (`lead_submit` / `survey_complete`).
- Розподіл обраних форматів і рівнів ризику — чи є попит саме на «під ключ» або на супровід.
- Голоси за перспективні напрями — перевірка гіпотез про платформу, аналітику, аудит і дані.
